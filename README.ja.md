# Startup India GOAT

`startup-india-goat` は、インドのスタートアップ 1 社または限定されたグループを、出典付きの証拠で調査する Agent Skill です。自然言語を受け付け、収集前に調査契約を表示し、公開情報と明示的に許可されたセッションを区別します。

利用可能な範囲で GitHub、Reddit、X、YouTube、Web、YourStory、Screener、The Ken、Inc42、Startup India、Tracxn、LinkedIn を調べます。ペイウォール、CAPTCHA、クォータ、認証、スキーマ変更は正直に表示します。

各実行は Markdown、HTML、バージョン付き JSON、サニタイズ済み証拠、マニフェストを `STARTUP_GOAT_MEMORY_DIR`（既定 `~/Documents/StartupIndiaGOAT/`）に保存します。GOAT 評価は定性的で、不透明な総合点は出しません。

[`skills/startup-india-goat/SKILL.md`](skills/startup-india-goat/SKILL.md) と [`CONFIGURATION.md`](CONFIGURATION.md) を参照してください。
