# Startup India GOAT

`startup-india-goat` ist eine Agent-Skill für evidenzbasierte Recherche zu einem indischen Startup oder einer begrenzten Startup-Gruppe. Sie akzeptiert natürliche Sprache, zeigt vor der Datenerhebung einen Recherchevertrag und trennt öffentliche Daten von ausdrücklich autorisierten Sitzungen.

Die Quellen umfassen je nach Verfügbarkeit GitHub, Reddit, X, YouTube, Web, YourStory, Screener, The Ken, Inc42, Startup India, Tracxn und LinkedIn. Paywalls, CAPTCHA, Quoten, Authentifizierung und Schemaänderungen werden ehrlich ausgewiesen.

Jeder Lauf speichert Markdown, HTML, versioniertes JSON, bereinigte Rohbelege und ein Manifest in `STARTUP_GOAT_MEMORY_DIR` (Standard: `~/Documents/StartupIndiaGOAT/`). Die GOAT-Rubrik ist qualitativ und erzeugt keine undurchsichtige Gesamtpunktzahl.

Siehe [`skills/startup-india-goat/SKILL.md`](skills/startup-india-goat/SKILL.md) und [`CONFIGURATION.md`](CONFIGURATION.md).
