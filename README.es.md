# Startup India GOAT

`startup-india-goat` es una skill de agente para investigar con evidencia citada una startup india o un grupo limitado. Acepta lenguaje natural, muestra un contrato de investigación antes de recopilar datos y separa las fuentes públicas de las sesiones autorizadas explícitamente.

Según su disponibilidad, cubre GitHub, Reddit, X, YouTube, Web, YourStory, Screener, The Ken, Inc42, Startup India, Tracxn y LinkedIn. Los paywalls, CAPTCHA, cuotas, autenticación y cambios de esquema se informan con honestidad.

Cada ejecución guarda Markdown, HTML, JSON versionado, evidencia bruta saneada y un manifiesto en `STARTUP_GOAT_MEMORY_DIR` (por defecto `~/Documents/StartupIndiaGOAT/`). La rúbrica GOAT es cualitativa y no produce una puntuación compuesta opaca.

Consulta [`skills/startup-india-goat/SKILL.md`](skills/startup-india-goat/SKILL.md) y [`CONFIGURATION.md`](CONFIGURATION.md).
