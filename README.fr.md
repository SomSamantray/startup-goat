# Startup India GOAT

`startup-india-goat` est une skill agent pour rechercher une startup indienne ou un groupe limité avec des preuves citées. Elle accepte des demandes en langage naturel, affiche un contrat de recherche avant toute collecte et distingue les données publiques des sessions explicitement autorisées.

Les sources couvrent GitHub, Reddit, X, YouTube, le Web, YourStory, Screener, The Ken, Inc42, Startup India, Tracxn et LinkedIn selon leur disponibilité. Les paywalls, CAPTCHA, quotas, authentification et dérives de schéma sont signalés honnêtement.

Chaque exécution enregistre Markdown, HTML, JSON versionné, preuves brutes assainies et manifeste dans `STARTUP_GOAT_MEMORY_DIR` (par défaut `~/Documents/StartupIndiaGOAT/`). La rubrique GOAT est qualitative et n'émet pas de score composite opaque.

Consultez [`skills/startup-india-goat/SKILL.md`](skills/startup-india-goat/SKILL.md) et [`CONFIGURATION.md`](CONFIGURATION.md).
